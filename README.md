# Maqueiro Simulator

Este é o meu primeiro projeto em Python! Criei este programa para simular o dia a dia de um maqueiro dentro de um hospital.

O sistema controla:
- Quais leitos estão livres ou ocupados.
- Se o paciente precisa de maca ou cadeira de rodas.
- Se o maqueiro lavou as mãos e colocou a roupa de proteção (EPI).
- A entrada e saída dos funcionários no plantão.

Fiz esse projeto para treinar a lógica de programação que estou aprendendo na faculdade.
